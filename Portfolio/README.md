# Personal Portfolio

This is my personal portfolio website where I have added information about me, my skills, projects, and contact details.

## About

This portfolio is made using basic web technologies. It is responsive and works on mobile, tablet, and desktop screens.

## Technologies Used

- HTML
- CSS
- JavaScript

## Features

- Responsive design
- About me section
- Skills section
- Project section
- Contact section
- Mobile navigation
- Smooth scrolling
- Dark/Light mode

## Projects

I have added some of my projects in the Projects section.

Each project includes:
- Project name
- Short description
- Technologies used
- GitHub or live project link

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

You can also use the Live Server extension in VS Code to run the website.
